تحليلات المواقع
من Google Analytics: انتقل إلى Admin → Data Streams → اختر موقعك → انسخ Measurement ID.
الغرض: تتبع الزوار والسلوك والصفحات الأكثر زيارة.
مثال: G-ABCDEF1234
من Search Console: أضف الموقع → اختيار طريقة HTML → انسخ محتوى content فقط.
الغرض: مراقبة أداء الموقع في نتائج البحث.
مثال: abcdef1234567890abcdef1234567890
رابط الموقع الكامل كما يظهر في Search Console.
الغرض: ربط Search Console Dashboard بلوحة التحكم مستقبلاً.
مثال: https://techdosenews.com
من Clarity: أنشئ مشروع → انسخ Project ID من كود التتبع.
الغرض: تسجيل جلسات المستخدمين وخرائط الحرارة (Heatmaps).
مثال: abcdef1234
من GoatCounter: سجل → انسخ رابط الموقع من Dashboard.
الغرض: تحليلات خفيفة وسريعة بدون تأثير على الأداء.
مثال: https://tdn.goatcounter.com
من Plausible: أضف موقعك → انسخ اسم الدومين.
الغرض: تحليلات خصوصية مفتوحة المصدر.
مثال: techdosenews.com
من Umami: Settings → Websites → انسخ Website ID.
الغرض: تحليلات ذات استضافة ذاتية (Self-hosted).
مثال: abc12345-xxxx-xxxx-xxxx-xxxxxxxxxxxx
رابط ملف script.js الخاص بخادم Umami الخاص بك.
مثال: https://analytics.example.com/script.js

الغرض: إرسال المقالات الجديدة تلقائياً للقناة.
آيدي القناة (يبدأ بـ @).
الغرض: تحديد وجهة الإرسال.
رابط القناة العامة (زر متابعة).

redirect = رابط مباشر، bot = إرسال عبر البوت.
من Discord: Server Settings → Integrations → Webhooks → New Webhook → انسخ الرابط.
الغرض: إشعارات المقالات الجديدة على سيرفر ديسكورد.
من Slack: أنشئ Incoming Webhook → انسخ الرابط.
الغرض: إشعارات المقالات الجديدة على سلاك.
الغرض: إرسال إشعارات البريد عند نشر مقالات جديدة (يتطلب خدمة SMTP خارجية).

الرابط النهائي للموقع بعد شراء الدومين.
الغرض: استخدامه في الـ sitemap والـ canonical والـ RSS.
مثال: https://techdosenews.com
الدومين الأساسي (بدون www).
الغرض: منع مشاكل المحتوى المكرر (Duplicate Content).
مثال: techdosenews.com
الرابط الكامل لملف robots.txt.
الغرض: توجيه محركات البحث لأرشفة الموقع.
مثال: https://techdosenews.com/robots.txt
الرابط الكامل لملف sitemap.xml.
الغرض: تسريع فهرسة الموقع.
مثال: https://techdosenews.com/sitemap.xml
من Google Search Console: إضافة ملكية الموقع → طريقة DNS أو HTML.
الغرض: إثبات ملكية الموقع لجوجل.
مثال: google-abc123def456
من Bing Webmaster Tools: أضف موقعك → انسخ علامة التحقق.
الغرض: إثبات ملكية الموقع لبنج.
مثال: bing-abc123def456
من Yandex Webmaster: أضف موقعك → انسخ علامة التحقق.
الغرض: إثبات ملكية الموقع لياندكس.
مثال: yandex-abc123def456
